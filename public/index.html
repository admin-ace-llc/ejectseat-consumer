How EjectSeat works

A real-time risk score for any US-listed public company or Foreign Private Issuer — built only from public, named sources.

01

Public filings, in real time

We continuously read SEC EDGAR — the official US securities filings repository — alongside named editorial sources from major publications. Every score is generated on demand from the most recent available data.

02

Proprietary intelligence layer

Our analysis stack classifies each company's current state, extracts structured intelligence about restructuring activity where present, and weighs corroborating signals across filings and verified press coverage. The output is a single 0–100 score with supporting context.

03

What we exclude

Reddit. Blind. LinkedIn. X / Twitter. Glassdoor. Anonymous tips. None of these contribute to any EjectSeat score. We only weight named, accountable sources — that's what makes the score defensible.
